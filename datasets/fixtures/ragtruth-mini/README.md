**SYNTHETIC TEST FIXTURE — NOT OFFICIAL RAGTRUTH RESULTS.**

and artifact tests. It contains QA, Summary, and Data2txt examples, multiple
human spans, `implicit_true`, `due_to_null`, non-good quality values, and one
